
# Fitness Analytics Dashboard 🏋️‍♂️

An interactive fitness analytics and workout planning application developed using **Python, Pandas, and Streamlit**.

### 🚀 Key Features
- Interactive exercise exploration and filtering.
- Muscle-group-based exercise selection.
- Personalized workout planning.
- Structured fitness dataset processing using Pandas.
- User-friendly interactive dashboard built with Streamlit.

### 🛠️ Tech Stack
- Python
- Pandas
- Streamlit
- CSV Dataset

### 🎯 Project Objective
To develop an interactive, data-driven fitness application that simplifies exercise discovery and helps users organize personalized workout routines.
